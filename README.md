# 勝手にランキング選手権 🏆

飲み会向けの匿名ランキング投票ゲーム。幹事が部屋を作り、参加者はQRコードまたは5文字のコードからスマホで参加します。

## 遊び方

1. 幹事が「幹事として始める」を押すと「橋野」で自動参加します。
2. 参加者は参加リンク・QRコード・部屋コードから、自分の名前で参加します。
3. 幹事を含め2人以上で開始し、「この中で一番面白いのは誰？？」に投票します。幹事も同じ画面から投票できます。自分への投票は禁止です。
4. 幹事が結果を発表します。橋野が最多得票（同率1位を含む）なら全員の結果画面に写真を表示し、幹事の端末で「企画経理に橋野あり！」の音声を再生します。
5. 「もう一度投票する」で同じ質問を繰り返せます。他のお題や質問追加はありません。

音声が自動再生されない場合は、結果画面の「音声を再生する」を押してください。端末のメディア音量は端末側で調整してください。

## 起動・公開

Python 3.10以降で `pip install -r requirements.txt` のあと `python app.py` を実行します。
環境変数 `PORT`（既定8000）を読み込み、`0.0.0.0` で待ち受けます。
Renderでは `render.yaml` またはPython Web Service（Free）として公開できます。

2〜40人対応。部屋と投票データはサーバーのメモリに保存され、再起動で消えます。操作のない部屋は約8時間で削除されます。1インスタンスで動かしてください。
