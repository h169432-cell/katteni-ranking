# 勝手にランキング選手権 🏆

飲み会向けの匿名ランキング投票ゲーム。幹事が部屋を作り、参加者はQRコードまたは5文字のコードからスマホで参加します。

## 遊び方

1. 幹事が「幹事として始める」を押す。
2. QRコードをスクリーンに表示し、全員が名前を入れて参加する。
3. オリジナルの質問を使いたい場合は、幹事画面の「質問を追加」に入力して「この質問を追加」を押す。
4. 2人以上集まったら「最初のお題へ」を押す。
5. 参加者が自分以外に匿名投票する。幹事は投票人数を確認できる。
6. 幹事が「結果を発表する」を押すと、ランキングと面白い称号が一斉に公開される。
7. 「次のお題へ」で繰り返す。元の30問と追加した質問のすべてが、ひととおり出るまで重複せずランダム出題される。

## ローカルで起動

Python 3.10以降を用意し、プロジェクトフォルダで実行します。

```bash
python -m pip install -r requirements.txt
python app.py
```

ブラウザで `http://localhost:8000` を開きます。同じWi-Fiに接続したスマホから参加するときは、PCのLAN内IPを使った `http://192.168.x.x:8000` などのURLで**幹事画面も**開いてください（`localhost` のQRはスマホから利用できません）。OSのファイアウォールでも8000番ポートのアクセスを許可してください。

## ネットに公開して遊ぶ

`render.yaml` が含まれているため、RenderなどのPythonが動くWebホスティングにこのフォルダを配置し、`python app.py` で起動できます（サーバー側は環境変数 `PORT` を読み込みます）。

公開URLを幹事が開いて部屋を作れば、QRコード経由で各スマホから参加できます。`http://localhost` のままではインターネット越しに参加できません。

## ゲーム仕様

- 2〜40人、元の30種類のお題＋幹事が追加した質問、匿名投票、自分への投票は禁止。
- 幹事はスマホから1〜120文字の質問を1部屋につき最大100問追加可能。投票中でも追加でき、以後のラウンドから抽選対象になる。追加した質問の称号は「みんなが選んだNo.1」。
- 追加した質問はその部屋だけで利用でき、別の部屋には引き継がれません。サーバー再起動でも消えます。
- 結果発表前は票の内訳を非表示。参加者・幹事には「投票済み人数」だけ表示。
- 同点1位にも対応。途中参加した人は次のお題から投票可能。
- 同じブラウザならリロード後も再参加可能（ブラウザのlocalStorageにトークンを保存）。
- 追加のDBは使いません。部屋と投票データはサーバーのメモリ上だけに保存。**サーバー再起動で消去**、操作のない部屋は約8時間で自動削除。
- 1台のサーバーで動かしてください（複数台に分散すると部屋情報を共有できません）。
- ネット回線によって画面の同期には通常1〜2秒ほどかかります。
- 幹事は参加者には数えません。幹事も投票するなら別のブラウザ/端末で参加してください。

## 注意事項

アカウント登録・個人情報収集はありませんが、実名ではなくニックネームで遊ぶことを推奨します。公開する場合はHTTPS付きのホスティングを使ってください。
